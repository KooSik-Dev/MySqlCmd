먼저 보기: 명령어를 어디에 입력하나요?

이 가이드에서는 입력하는 곳이 3군데 나옵니다. 명령어 위의 파란 표시만 확인하면 됩니다.

① 파일 탐색기 주소창 폴더 위쪽에 현재 경로가 보이는 칸입니다.
여기에는 cmd만 입력합니다.
② CMD(명령 프롬프트) 검은색 창에 C:\...>처럼 보이는 화면입니다.
SQLite 설치와 실행 명령어를 입력합니다.
③ SQLite 화면 SQLite를 실행한 뒤 sqlite>가 보이는 화면입니다.
SELECT, .tables 같은 DB 명령어를 입력합니다.
가장 쉬운 구분법:
앞에 C:\...>가 보이면 CMD, sqlite>가 보이면 SQLite입니다.
STEP 1

연습용 폴더 만들기

바탕화면처럼 찾기 쉬운 곳에서 빈 공간에 마우스 오른쪽 클릭 → 새로 만들기 → 폴더를 눌러 연습용 폴더를 만듭니다.

sql연습

예시 이미지처럼 새 폴더를 만든 뒤 이름을 sql연습처럼 알아보기 쉽게 바꾸면 됩니다. 앞으로 SQLite 실행 파일과 DB 파일을 이 폴더 안에서 관리합니다.

예시 화면: 바탕화면에서 새 폴더를 만드는 모습

바탕화면 빈 곳에서 오른쪽 클릭 → 새로 만들기 → 폴더를 누르면 새 폴더를 만들 수 있습니다.
STEP 2

sql연습 폴더에서 CMD 열기

sql연습 폴더를 연 다음, 파일 탐색기 맨 위의 주소창을 클릭합니다. 이미지처럼 경로가 파랗게 선택되면 맞게 누른 것입니다.

입력 위치: 파일 탐색기 주소창 
cmd

그 상태에서 주소를 지우고 cmd를 입력한 뒤 Enter를 누르면, 현재 폴더 위치에서 검은색 CMD 창이 열립니다.

CMD 창에 C:\...\sql연습>처럼 보이면 준비 완료입니다.

아래 두 이미지를 순서대로 보면 됩니다. 먼저 주소창 클릭, 그다음 cmd 입력입니다.

1단계: 주소창을 클릭하면 현재 폴더 경로가 파랗게 선택됩니다.
2단계: 선택된 경로 대신 cmd를 입력하고 Enter를 누르면 CMD가 열립니다.
STEP 3

SQLite 처음 설치하기

설치 명령어 복사 → CMD에 붙여넣기 → Enter → sqlite> 확인

설치는 처음 한 번만 합니다. 긴 명령어를 외울 필요는 없고, 복사해서 CMD에 붙여넣은 뒤 Enter를 누르면 됩니다.

① 설치 명령어 실행

입력 위치: CMD 
powershell -NoProfile -ExecutionPolicy Bypass -Command "$ErrorActionPreference='Stop'; $p=Invoke-WebRequest 'https://sqlite.org/download.html'; $h=$p.Links | Where-Object { $_.href -match 'sqlite-tools-win-x64.*\.zip$' } | Select-Object -First 1 -ExpandProperty href; if(!$h){throw 'SQLite 다운로드 파일을 찾지 못했습니다.'}; if($h -notmatch '^https?://'){$h='https://sqlite.org/'+$h.TrimStart('/')}; Invoke-WebRequest $h -OutFile sqlite.zip; Remove-Item '.\sqlite-temp' -Recurse -Force -ErrorAction SilentlyContinue; Expand-Archive sqlite.zip -DestinationPath '.\sqlite-temp' -Force; Remove-Item sqlite.zip -Force; $e=Get-ChildItem '.\sqlite-temp' -Recurse -Filter sqlite3.exe | Select-Object -First 1; if(!$e){throw 'sqlite3.exe를 찾지 못했습니다.'}; Copy-Item $e.FullName '.\sqlite3.exe' -Force; Remove-Item '.\sqlite-temp' -Recurse -Force; & '.\sqlite3.exe' 'practice.db'"

위 명령어에서 복사를 누른 뒤, 검은색 CMD 창에서 붙여넣고 Enter를 누릅니다.

실제 화면은 이렇게 긴 명령어가 여러 줄처럼 보일 수 있습니다. 그대로 Enter를 누르면 됩니다.

② 설치된 파일 확인

설치가 끝나면 처음 만든 폴더 안에 아래 두 파일이 생깁니다.

화면에 보이는 파일역할
sqlite3SQLite를 실행하는 프로그램
practice테이블과 데이터가 저장되는 DB 파일입니다. 처음에는 아직 저장된 데이터가 없어서 이 파일이 바로 안 보일 수도 있습니다. 그럴 때는 오류라고 생각하지 말고, 당황하지 않아도 됩니다. 그대로 다음 단계로 진행해도 됩니다.
practice 파일이 바로 안 보여도 괜찮습니다.
처음에는 아직 DB에 저장된 내용이 없어서 파일이 눈에 안 보일 수 있습니다. 설치가 실패한 것으로 생각하지 말고 다음 단계로 그대로 진행하세요.
Windows 설정에 따라 확장자가 숨겨져서 sqlite3.exe가 sqlite3, practice.db가 practice로 보일 수 있습니다.
이미지처럼 sqlite3와 practice 두 파일이 보이면 설치가 정상적으로 된 것입니다.

③ SQLite가 열렸는지 확인

CMD 화면 맨 아래에 sqlite>가 보이면 끝입니다. 이제부터 SQL 명령어는 그 sqlite> 뒤에 입력합니다.

성공 표시: sqlite>
STEP 4

다음부터 SQLite 다시 열기

STEP 3 설치는 한 번만 합니다. 다음부터는 설치 명령어를 다시 쓰지 않고, 아래 실행 명령어만 사용합니다.

1. sql연습 폴더를 엽니다.
2. 주소창에 cmd를 입력해서 CMD를 엽니다.
3. 열린 CMD에 아래 명령어를 입력합니다.

입력 위치: CMD 
.\sqlite3.exe practice.db

Enter를 누른 뒤 이미지처럼 sqlite>가 보이면 practice.db가 정상적으로 열린 것입니다.

sqlite>

현재 열린 DB를 확인하고 싶다면:

입력 위치: SQLite (sqlite>) 
.databases
기억할 것: .\sqlite3.exe practice.db는 CMD에 입력하고, .tables, SELECT 같은 명령은 sqlite> 화면에 입력합니다.

아래 이미지는 다시 열기 과정입니다. 먼저 CMD에서 실행 명령어를 입력하고, 그다음 sqlite>가 뜨는지 확인합니다.

1단계: CMD에 .\sqlite3.exe practice.db 를 입력합니다.
2단계: Enter를 누른 뒤 sqlite> 가 나오면 practice.db가 정상적으로 열린 것입니다.
STEP 5

SQLite 기본 명령어

여기부터는 설명을 길게 외우기보다 “명령어가 무슨 기능인지”만 익히면 됩니다.

입력 위치: SQLite (sqlite>)
명령어기능
.tables테이블 목록 보기
.schema전체 테이블 구조 보기
.schema studentstudent 테이블 구조 보기
.databases현재 열려 있는 DB 확인
.headers on조회 결과에 컬럼 이름 표시
.mode column조회 결과를 표처럼 정렬
.help도움말 보기
.quitSQLite 종료
점(.)으로 시작하는 SQLite 명령어에는 세미콜론(;)을 붙이지 않습니다.
STEP 6

CREATE TABLE - 테이블 만들기

기능: 데이터를 저장할 표의 틀을 만듭니다.

입력 위치: SQLite (sqlite>) 
CREATE TABLE student (
    학번 NUMERIC(10),
    이름 CHAR(10),
    주소 VARCHAR(100)
);
부분뜻
student테이블 이름
학번, 이름, 주소컬럼(항목) 이름
NUMERIC숫자 형태 데이터
CHAR / VARCHAR문자 형태 데이터

만들어졌는지 확인:

.tables

구조 확인:

.schema student
지금은 자료형을 완벽하게 외우기보다 “테이블 안에 어떤 항목을 저장할지 정한다” 정도로 이해하면 충분합니다.
STEP 7

데이터 추가 / 조회 / 수정 / 삭제

입력 위치: SQLite (sqlite>)

INSERT

기능: 데이터 추가

INSERT INTO student (학번, 이름, 주소)
VALUES (20260001, '홍길동', '서울');

SELECT

기능: 데이터 조회

SELECT * FROM student;

UPDATE

기능: 기존 데이터 수정

UPDATE student
SET 주소 = '인천'
WHERE 학번 = 20260001;

DELETE

기능: 데이터 삭제

DELETE FROM student
WHERE 학번 = 20260001;
UPDATE / DELETE에서 WHERE는 특히 중요합니다. WHERE가 없으면 여러 데이터가 한꺼번에 바뀌거나 삭제될 수 있습니다.
STEP 8

자주 쓰는 SELECT 명령어

입력 위치: SQLite (sqlite>)
명령어기능
SELECT * FROM student;모든 데이터 조회
SELECT 학번, 이름 FROM student;학번과 이름만 조회
SELECT * FROM student WHERE 주소 = '서울';조건에 맞는 데이터만 조회
SELECT * FROM student ORDER BY 학번 ASC;학번 기준 오름차순 정렬
SELECT COUNT(*) FROM student;데이터 개수 세기
SELECT DISTINCT 주소 FROM student;중복 주소를 하나씩만 조회
SELECT * FROM student WHERE 이름 LIKE '김%';'김'으로 시작하는 이름 검색
ASC = 오름차순 / DESC = 내림차순
% = 뒤에 어떤 글자가 와도 된다는 뜻
STEP 9

SQLite 종료하기

입력 위치: SQLite (sqlite>) 
.quit

종료해도 만든 테이블과 데이터는 practice.db에 저장되어 있습니다.

다음에 다시 열 때는 sql연습 폴더에서 CMD를 연 뒤 아래 명령어를 사용합니다.

입력 위치: CMD 
.\sqlite3.exe practice.db

문제 해결

아래 문제 해결 명령은 특별한 표시가 없으면 SQLite의 sqlite> 화면에 입력합니다.

1. .tables를 입력했는데 아무것도 안 나옴

현재 열린 DB를 먼저 확인합니다.

.databases

practice.db가 열려 있지 않다면:

.open practice.db

2. 아래 문구가 나옴

Connected to a transient in-memory database.

임시 메모리 DB가 열린 상태입니다. 아래 명령으로 practice.db를 엽니다.

.open practice.db

3. no such table 오류

Parse error: no such table: student

현재 DB에 해당 테이블이 없다는 뜻입니다. 먼저 목록을 확인합니다.

.tables

4. SELECT 결과를 보기 좋게 출력하기

.headers on
.mode column

그 다음 조회:

SELECT * FROM student;
